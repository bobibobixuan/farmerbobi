## 🌏 About

**Farmer Bobi** (mod ID: `bobidelight`, Chinese: **波比乐事**) is a content-rich add-on for the [Farmer's Delight](https://modrinth.com/mod/farmers-delight) mod that introduces a complete farm-to-table Chinese and Asian cuisine system into Minecraft 1.20.1.

Starting from 5 fast-food items, the mod has grown into a full-featured dual-platform content pack with **33 plantable crops, 100+ recipes, 30+ cooked dishes, 8 drinks, 18 feast blocks**, and a full suite of processed ingredients, sauces, and condiments.

> [!IMPORTANT]
> **Hard Dependency** — Farmer's Delight (Fabric or Forge) must be installed. The mod will refuse to load without it.

### Design Philosophy

- **Farm to table** — every dish traces back to a crop you can grow
- **Vanilla+ aesthetic** — textures and models blend seamlessly with Minecraft and Farmer's Delight
- **Dual platform parity** — Fabric and Forge variants ship identical gameplay content
- **Self-contained** — no third-party library dependencies beyond Farmer's Delight itself

2. Place it in your `mods/` folder alongside Farmer's Delight
3. Launch the game

## 🔧 Building from Source

### Prerequisites

- **JDK 21** (compiles to Java 17 bytecode via `--release 17`)
- **Gradle 8.14+** (wrapper included — no system Gradle required)

### Build

```bash
# Clone the repository
git clone https://github.com/bobibobixuan/farmerbobi.git
cd farmerbobi

# Build both Fabric and Forge
./gradlew build

# Build a single platform
./gradlew :fabric:build
./gradlew :forge:build
```

### Run Client

```bash
./gradlew :fabric:runClient   # Fabric
./gradlew :forge:runClient    # Forge
```

Output artifacts: `fabric/build/libs/` and `forge/build/libs/`.

## 🤝 Contributing

Contributions are welcome! Here's how you can help:

1. **Report bugs** — open an [Issue](https://github.com/bobibobixuan/farmerbobi/issues) with your Minecraft version, mod loader, and steps to reproduce
2. **Suggest features** — open a [Discussion](https://github.com/bobibobixuan/farmerbobi/discussions) with your idea
3. **Submit PRs** — fork the repo, create a feature branch, and open a Pull Request against `main`

### Development Guidelines

- Test on **both** Fabric and Forge before submitting
- Keep Fabric and Forge resource trees in sync (blockstate, model, texture, lang, data)
- Follow existing code style — no new abstractions unless justified
- Run `./gradlew build` before pushing
