# bobiDelight 1.4.2 更新日志

发布日期：2026-05-06

## 概览

1.4.2 是对 1.4.1 参考库贴图替换工作的继续收束。这一版的重点不是再扩一轮近似替换，而是把整合包参考库完整复查一遍，只保留真正属于同名作物或同名物品的安全复用项，并把上一版尚未接上的 crate 资源补到可实际显示的状态。

## 全库扫描结论

- 本次重新扫描了整合包 Farmer's Delight 参考库中的全部 `asset-index.json`。
- 只认以下 5 类安全可复用资源：
  - produce item
  - seeds item
  - wild crop
  - crop stage
  - crate 顶面 / 侧面贴图
- 排除了所有只是菜名里带作物词的成品菜资源，例如 corn soup、fried eggplant pasta、mint milkshake 等。
- 重新确认后，当前参考库中对 bobiDelight 真正有直接价值的同名目标主要集中在：
  - corn
  - cucumber
  - eggplant
  - ginger
  - hamburger

## 资源接入

- 保持 1.4.1 中已经落地的同名资源替换：
  - Corn Delight：玉米 produce / seeds / wild / crop stages
  - Cultural Delights：黄瓜 produce / seeds / wild / crop stages（映射后接入）
  - Cultural Delights：茄子 produce / seeds / wild / crop stages（映射后接入）
  - Cultural Delights：姜 item
  - Farmer's Delight：汉堡 item
- 新增并接入了 corn、cucumber、eggplant 三组独立 crate 资源：
  - corn crate 贴图复用 Corn Delight
  - cucumber crate 贴图复用 Cultural Delights
  - eggplant crate 贴图复用 Cultural Delights
- 上述 crate 资源已同步写入 Fabric 与 Forge 双端资源目录。

## 模型与资源结构调整

- 为 corn、cucumber、eggplant 新增了各自独立的 block model：
  - `bobixuan_corn_crate`
  - `bobixuan_cucumber_crate`
  - `bobixuan_eggplant_crate`
- Fabric / Forge 双端对应的 crate blockstate 与 item model 都已从通用 `template_crate` 切换到各自独立的 crate model。
- 这样处理后，三组箱装作物终于会实际显示各自的 crate 顶面 / 侧面贴图，而不是继续共用 Farmers Delight 的默认 potato crate 外观。
