# bobiDelight 1.4.1 更新日志

发布日期：2026-05-06

## 概览

1.4.1 是一次以资源替换为主的 patch 更新。这一版没有扩展新内容注册，也没有调整作物或食物的逻辑行为，核心目标是把已经整理好的整合包参考库素材真正落到 bobiDelight 本体资源中，先完成一批高收益、低风险的贴图替换。

本次替换优先遵循“先复用整合包里质量更高、结构兼容的 Farmer's Delight 关联素材，再决定是否自制”的规则。

## 资源与美术

- 玉米整套贴图改为复用 Corn Delight，对应覆盖：
  - crop stage0 / stage4 / stage5 / stage6 / stage7
  - wild crop
  - produce item
  - seeds item
- 黄瓜整套贴图改为复用 Cultural Delights，对应覆盖：
  - crop stage0 / stage4 / stage5 / stage6 / stage7
  - wild crop
  - produce item
  - seeds item
- 茄子整套贴图改为复用 Cultural Delights，对应覆盖：
  - crop stage0 / stage4 / stage5 / stage6 / stage7
  - wild crop
  - produce item
  - seeds item
- 姜的物品贴图改为复用 Cultural Delights。
- 汉堡物品贴图改为复用 Farmer's Delight 原版素材。
- 鸡翅物品贴图改为复用 Display Delight 的 hot wings 近似素材，作为当前语义最接近且画面质量更高的现成替换。
- 上述 PNG 已同步覆盖到 Fabric 与 Forge 双端资源目录，避免两端贴图再次分叉。

## 阶段映射说明

- bobiDelight 当前黄瓜与茄子仍使用 stage0 / stage4 / stage5 / stage6 / stage7 这套命名。
- Cultural Delights 原始作物阶段为 stage0 到 stage5，并且其 blockstate 映射为：
  - age0 -> stage0
  - age1 -> stage1
  - age2 -> stage2
  - age3 / age4 -> stage3
  - age5 / age6 -> stage4
  - age7 -> stage5
- 为保持现有模型与 blockstate 结构不扩散，本次仅做贴图映射替换：
  - bobiDelight stage0 <- Cultural Delights stage0
  - bobiDelight stage4 <- Cultural Delights stage3
  - bobiDelight stage5 <- Cultural Delights stage4
  - bobiDelight stage6 <- Cultural Delights stage4
  - bobiDelight stage7 <- Cultural Delights stage5
- 玉米这条直接复用 Corn Delight 的对应同名阶段贴图，结构上与当前 bobiDelight 更接近，因此不需要额外改 blockstate。

## 工程说明

- 本次没有修改注册逻辑、配方、语言文件或世界生成逻辑。
- 资源替换前先核对了参考模组的 model 与 blockstate，避免把阶段数或 parent 结构不兼容的贴图直接覆盖进来。
- 替换过程中对代表性资源做了 SHA256 哈希抽查，确认参考库源文件已经实际覆盖到目标 PNG。
